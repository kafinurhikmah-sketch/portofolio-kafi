Tentang Saya

Dedikasi pada Clean Code & Solusi Skalabilitas

Menggabungkan keahlian logika komputasi backend yang solid dengan desain pengalaman pengguna yang intuitif di perangkat web dan mobile.

Saya adalah seorang Full-Stack Web & Mobile Developer yang berkomitmen menghadirkan produk digital berkualitas tinggi, tangguh, dan siap pakai untuk industri. Berfokus pada penulisan kode bersih (Clean Code), pemisahan arsitektur yang modular, serta pemanfaatan pola desain perangkat lunak (Design Patterns) yang tepat guna.

Di sisi Web Development, saya berpengalaman membangun aplikasi interaktif menggunakan React, Next.js, dan Tailwind CSS, yang didukung arsitektur backend kokoh menggunakan Node.js, Express, PHP (Laravel), Python, serta manajemen basis data relasional (PostgreSQL, MySQL) maupun non-relasional (MongoDB).

Di ranah Mobile Development, saya mengembangkan aplikasi lintas platform performa tinggi menggunakan Flutter dan React Native. Saya mengutamakan kelancaran frame rate (60/120fps), efisiensi manajemen state, integrasi API real-time, serta kemampuan sinkronisasi offline untuk memberikan pengalaman pengguna terbaik.

Bagi saya, perangkat lunak yang hebat bukan hanya yang tampak menarik di permukaan, melainkan juga yang memiliki fondasi data yang aman, responsivitas tinggi di saat beban puncak, dan mudah dirawat oleh tim developer di masa mendatang.
